# CK-Mailer

This solution contains:
- [CK.Mailer](./CK.Mailer/README.md): The "MailSender" feature of [CK-AppIdentity](https://github.com/signature-opensource/CK-AppIdentity): the named senders of each local party.
- [CK.Mailer.MailKit](./CK.Mailer.MailKit/README.md): The "MailKit" senders ([MailKit](https://github.com/jstedfast/MailKit)): an SMTP server or a pickup directory.
- [CK.IO.MailRelay](./CK.IO.MailRelay/README.md): The `[Internal]` command that a remote party sends to a "MailRelay" party.
- [CK.AppIdentity.MailRelay.Local](./CK.AppIdentity.MailRelay.Local/README.md): The "MailRelay" asymmetric feature, Local side: a local party sends the mails of its remote parties.
- [CK.AppIdentity.MailRelay.Remote](./CK.AppIdentity.MailRelay.Remote/README.md): The "MailRelay" asymmetric feature, Remote side: a local party sends its mails through its relay parties.
