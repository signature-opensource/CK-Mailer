# CK.Mailer

The "MailSender" feature of CK-AppIdentity: each local party has its named senders (`MailSenders`, `MailSenderExtensions.GetMailSender`),
the default sender of the root party is the `IDefaultEmailSender`; a sender kind is a `MailSenderOption`. The mail is a `SimpleEmail`.

See the [README](https://github.com/signature-opensource/CK-Mailer/blob/stable/CK.Mailer/README.md).
